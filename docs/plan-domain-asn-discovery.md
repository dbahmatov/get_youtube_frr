# Implementation Plan: Domain-Driven ASN Discovery

Источник требований: `docs/spec-domain-asn-discovery.md`
Дата: 2026-07-30

---

## Overview

Переезд трёх скриптов в пакет `bgpfeed/` с заменой ручных ASN на конвейер
`geosite → резолв с vantage → Cymru → ASN → RADB → collapse → FRR`.

## Ключевые решения, влияющие на порядок работ

1. **Первый вертикальный срез — паритет со старым скриптом.** До всякого discovery
   гоняем существующий v1-конфиг через новый пакет и сверяем набор префиксов
   со старым `getroutes.py`. Это ловит регрессии фундамента до того, как
   сверху ляжет незнакомая логика.
2. **Сначала чистая логика, потом сеть.** `summarize`/`guards`/`select`/`budget`
   тестируются на фикстурах без единого мока. Сетевые модули — тонкие обёртки.
3. **Риск с наибольшей неопределённостью — vantage-резолв** (биндинг к source IP)
   и формат текстовых фидов. Оба выносим как можно раньше внутри своих фаз.
4. **Отладка резолва и FRR — только на `vds-kg`.** Локально гоняем тесты на фикстурах.

## Definition of Done (для каждой задачи)

- `python3 -m pytest tests/ -q` — зелёный
- Нет `shell=True` в `bgpfeed/`
- Публичные функции с type hints и docstring на русском
- Задача оставляет систему в рабочем состоянии
